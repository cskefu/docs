# 联系人

在春松客服中，**联系人管理（Contact Management）** 是其作为“轻量级 CRM”的核心体现。它不仅记录聊天历史，还能帮你构建完整的用户画像。

![](../../static/img/products/Pasted%20image%2020260219145751.png)

以下是管理联系人的核心维度和技巧：

---

## 1. 联系人自动捕获与识别

当客户通过不同渠道接入时，春松客服 会自动创建或匹配联系人：

- **网站插件：** 匿名访问者最初显示为“随机编号”。一旦他们在预聊天表单输入邮箱，或通过 API 传入身份信息，系统会自动更新资料。
    
- **社交媒体/邮件：** 系统会自动抓取其社交账号名或邮箱地址作为唯一识别标识。
    
- **合并重复项：** 如果同一个客户既发了邮件又在网页聊天，你可以通过邮箱地址将这两个“联系人身份”**合并 (Merge)**，确保对话历史不丢失。
    

---

## 2. 丰富联系人画像 (Profile)

在对话窗口的**右侧边栏**，你可以实时编辑联系人信息：

- **基础属性：** 姓名、邮箱、电话、公司名称。
    
- **地理位置：** 系统会根据 IP 自动显示城市、国家及当地时间（帮你判断现在回复是否会打扰对方）。
    
- **社交账号链接：** 手动关联其 LinkedIn 或 Twitter 页面。
    
- **自定义属性 (Custom Attributes)：** * 这是最强大的功能。你可以根据业务需求自定义字段，例如：“会员等级”、“订阅到期日”或“购买频率”。
    
    - _路径：设置 -> 自定义属性 -> 联系人属性。_
        

---

## 3. 联系人标签 (Labels)

标签是分类联系人的最快方式。

- **用途：** 标记“VIP客户”、“黑名单”、“开发者”、“潜在意向”等。
    
- **筛选：** 你可以在左侧导航栏的 `Contacts` 页面，通过标签快速筛选出一组特定的联系人进行集中查看。
    

---

## 4. 全局联系人列表 (Contacts 页面)

点击左侧菜单的 **Contacts** 图标，进入管理中心：

- **搜索与过滤：** 支持按姓名、邮箱、电话或标签进行全局搜索。
    
- **导入/导出：**
    
    - **导入：** 支持上传 CSV 文件批量导入存量客户数据。
        
    - **导出：** 将联系人资料导出为 CSV，用于营销推送或备份。
        
- **手动创建：** 即使没有聊天记录，你也可以手动点击 `New Contact` 录入客户信息，方便后续主动发起邮件会话。
    

---

## 5. 对话上下文同步

春松客服 允许你查看该联系人的**所有历史对话**。

- 即便客户一年前咨询过，右侧边栏也会显示“Previous Conversations”。
    
- 这能让接手的客服瞬间掌握背景，避免询问客户已经提供过的信息，极大地提升用户体验。
    

---

## 6. 高级进阶：SDK 身份验证

如果你在自己的 App 或网站中使用 春松客服，可以使用 **Identity Validation**：

- 通过加密的 `user_hash` 确保联系人信息的真实性，防止恶意用户冒用他人邮箱进行对话。
    

---

### 💡 实用小建议

建议您先去 **“设置 -> 自定义属性”** 中，根据您的业务逻辑增加 2-3 个关键字段（如：_订单号_ 或 _产品版本_）。这样当客服在聊天时，就能直接在右侧面板完善客户资料，而不需要频繁切换到后台 CRM。

**您是想了解如何通过 CSV 批量导入联系人，还是想知道如何通过 API 自动同步您现有数据库里的用户信息？**
