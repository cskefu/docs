# 微信公众号渠道

在春松客服中，**微信公众号（Wechat GHZ）** 渠道是其最核心、也是集成最成熟的渠道之一。通过它，你可以直接在 春松客服 后台回复客户发给微信公众号的 **客服** 消息。

以下是该渠道的功能介绍及配置流程：

---

## 1. 核心功能亮点

- **统一消息收件箱：** 客户通过微信公众号发送的消息会实时推送到春松客服。
    
- **无需共享账号：** 客服人员只需在春松客服后台操作，**无需登录公司的微信公众号运营者账号**，也无需拥有主页管理员权限，极大地提高了安全性。
    
- **完整对话上下文：** 在回复时可以查看客户历史对话消息。
    
- **协作增强：** 支持使用“私密便签”和同事讨论、通过标签分类对话、设置自动分配等。
    
- **多主页管理：** 你可以同时接入多个微信公众号，并分别指派给不同的客服团队。
    

---

## 2. 快速配置指南

如果你使用的是官方云服务 (春松客服 Cloud)，配置非常简单：

1. **添加收件箱：** 进入 `Settings` -> `Inboxes` -> `Add Inbox`。
    
2. **选择渠道：** 点击 `微信` 图标。
    
3. **添加配置信息：** 登陆微信公众号后台，获得密钥信息，并且回填到春松客服。
    
4. **分配坐席：** 选择哪些客服负责这个渠道。

---

## 3. 关键设置建议

- **工作时间设置：** 设置微信公众号渠道的在线时间，非工作时间可自动回复（防止微信的响应速度排名下降）。
    
- **渠道欢迎语：** 客户点击“发消息”时，自动发送第一条欢迎文案。
