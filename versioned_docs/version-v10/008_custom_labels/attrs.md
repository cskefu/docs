# 自定义属性

在春松客服中，**属性管理（Attribute Management）** 是将这个平台从简单的“聊天工具”升华为企业级 **轻量 CRM** 的核心逻辑。它允许你存储关于客户或对话的结构化数据，从而实现精准的服务和个性化的自动化。

![](../../../static/img/products/Pasted%20image%2020260219153203.png)


---

## 1. 属性的两大分类

春松客服 将属性严格划分为两个层级，这种分离确保了数据的逻辑清晰：

### **联系人属性 (Contact Attributes)**

- **定义：** 绑定在“人”身上的长期数据。
    
- **特点：** 无论该客户发起多少次聊天，这些信息都是跨对话持久存在的。
    
- **常用场景：** 会员等级、公司名称、客户经理、注册时间、偏好语言。
    

### **对话属性 (Conversation Attributes)**

- **定义：** 绑定在“单次聊天”上的短期数据。
    
- **特点：** 仅针对当前的咨询有效，不同的对话可以有不同的值。
    
- **常用场景：** 订单编号、产品型号、问题分类、满意度分数、紧急程度。
    

---

## 2. 支持的数据类型

在创建属性时，你需要选择合适的数据类型，这决定了客服输入的规范性：

|**类型**|**适用场景**|
|---|---|
|**文本 (Text)**|备注、详细地址、公司名。|
|**数字 (Number)**|消费总额、订单计数。|
|**列表 (Link/Dropdown)**|**最推荐**。预设选项（如：VIP、Gold、Silver），防止手动输入出错。|
|**布尔值 (Checkbox)**|是否已付费、是否黑名单。|
|**日期 (Date)**|合约到期日、最后购买日期。|

---

## 3. 如何创建自定义属性

1. 点击左下角 **设置 (Settings)** -> **自定义属性 (Custom Attributes)**。
    
2. 点击右上角 **添加自定义属性**。
    
3. 填写信息：
    
    - **显示名称**：客服看到的名称（如：订单号）。
        
    - **属性键 (Key)**：系统内部识别名，建议用英文（如：`order_id`）。
        
    - **描述**：解释该属性的作用。
        
    - **类型**：从上述表格中选择。
        

---

## 4. 属性的数据来源（如何填充数据？）

属性的管理不仅仅靠客服手动填写，更多时候是自动化完成的：

- **手动输入：** 客服在对话右侧边栏的“自定义属性”面板直接修改。
    
- **网站 SDK 自动同步：** 如果你是登录系统，可以使用 JS 代码自动传入。
    
    JavaScript
    
    ```
    window.cskefu.setCustomAttributes({
      plan: 'Enterprise',
      user_id: '9527'
    });
    ```
    
- **API 写入：** 通过后端接口，在客户下单后自动更新其在春松客服里的 `last_purchase_amount`。
    
- **自动化规则：** 根据特定条件自动更改属性。

## 5. 属性管理的高级价值

### **A. 动态分配路由**

你可以设置：如果联系人属性中的 `plan` 等于 `VIP`，则该对话自动跳过普通坐席，直接分配给“高级客服团队”。

### **B. 个性化预设回复**

在回复模板中使用占位符：

> “您好 {{contact.name}}，我看到您的订单号是 {{conversation.order_id}}，正在为您处理。”

### **C. 数据筛选与报告**

你可以导出所有 `plan` 为 `Enterprise` 的联系人列表，用于精准的营销回访。

---

### **管理小建议**

- **避免冗余：** 不要把所有信息都往属性里塞，只保留对“客服处理问题”或“自动化分流”有直接帮助的数据。
    
- **优先使用下拉框：** 尽量少用“文本”类型，多用“列表”类型。这样在做报表统计时，数据会非常干净，不会出现“vip”和“VIP”被算成两类的情况。
