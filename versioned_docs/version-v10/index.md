# 春松客服

[https://www.cskefu.com](https://www.cskefu.com)

春松客服支持企业完成客户服务工作，尤其是从下面的四项内容：

* 管理座席账号、团队和联系人
* 渠道、座席、访客构建连接
* 服务过程的 AI 效率工具
* 帮助管理团队进行监控、质检

春松客服也支持使用 API 接口完成自动化、业务流程化等，和外部系统集成连通。

* 通过[文档中心](/docs/)，可以进一步了解春松客服的业务能力
* 通过[API 文档](https://api-docs.cskefu.com/)，进一步了解系统集成 API
